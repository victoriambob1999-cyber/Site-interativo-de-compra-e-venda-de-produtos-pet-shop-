# 🐾 Salvatore Pet Spa — Estética & Bem-estar Animal

Site interativo desenvolvido para o **Salvatore Pet Spa**, focado no agendamento de serviços de estética e bem-estar para cães e gatos de forma prática e acolhedora.

## ✨ Funcionalidades
- Exibição de serviços principais, serviços adicionais e tabela de preços
- Banner promocional de 10% de desconto no primeiro atendimento
- **Carrinho de pedidos interativo:** seleção de serviços com cálculo automático do valor total
- **Integração com WhatsApp:** envio direto do resumo do pedido (com nome do tutor e do pet) para confirmação do agendamento

## 🛠️ Tecnologias Utilizadas
- HTML5
- CSS3
- JavaScript
